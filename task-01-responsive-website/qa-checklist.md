# QA Checklist

This checklist summarizes the testing completed before submitting the project.

## Functional Testing

- [x] Desktop navigation works correctly.
- [x] Mobile navigation opens and closes correctly.
- [x] Active navigation updates while scrolling.
- [x] Back to Top button works.
- [x] Statistics animation runs once.
- [x] Contact form validation works.
- [x] Success message appears after valid submission.
- [x] Character counter updates correctly.

## Accessibility

- [x] Keyboard navigation works.
- [x] Visible focus state exists.
- [x] aria-expanded implemented.
- [x] aria-invalid updated correctly.
- [x] aria-describedby connected to error messages.
- [x] aria-live used for success message.

## Responsive Testing

- [x] Desktop layout.
- [x] Tablet layout.
- [x] Mobile layout.

## Browser Testing

- [x] Google Chrome.
- [x] Microsoft Edge.

## Console

- [x] No JavaScript errors.
- [x] No unnecessary warnings.
